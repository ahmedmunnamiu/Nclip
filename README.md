# Nclip

AMOLED-black minimal Android app that saves **all notifications** and **everything you copy**.
Square UI, smooth animations, foreground service + battery-optimization exemption.

## Build (GitHub Actions)
1. Push this folder to a GitHub repo (branch `main`).
2. Open **Actions → Build Nclip APK** (runs automatically on push).
3. Download the **Nclip-APK** artifact → install `app-release.apk` (or `app-debug.apk`).

Local build: open in Android Studio (JDK 17) and run.
